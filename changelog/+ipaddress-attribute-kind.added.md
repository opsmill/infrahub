Added a new `IPAddress` attribute kind for storing bare IP addresses (IPv4 or IPv6) without a netmask or prefix. Unlike `IPHost`, which appends a `/32` or `/128`, an `IPAddress` value is stored and returned exactly as entered (e.g. `192.0.2.10`), and prefix notation (e.g. `10.0.0.1/24`) is rejected. Use it for DNS records, NTP/syslog/SNMP server addresses, monitoring targets, and other IP data that has no subnet context.
