In the GraphQL schema, the `node_metadata` field of the `NestedEdged` type of every generic can now be null: its type changes from `InfrahubNodeMetadata!` to `InfrahubNodeMetadata`, as it already was on the `NestedEdged` types of node kinds. Teams that generate client types from the GraphQL schema will see `node_metadata` on these types as optional and must handle a null value.
