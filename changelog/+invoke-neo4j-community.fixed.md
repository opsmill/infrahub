`uv run invoke demo.start` and the other `invoke` tasks now start Neo4j Community by default, matching the Docker Compose install. To run Neo4j Enterprise with online backup and the Prometheus metrics endpoint, set `NEO4J_DOCKER_IMAGE` to an Enterprise image, for example `neo4j:2026.05.0-enterprise`. If your local `invoke` database was created with Neo4j Enterprise, keep `NEO4J_DOCKER_IMAGE` set to an Enterprise image or delete the database volume, because Neo4j Community could not open a database created by Neo4j Enterprise in our upgrade tests.
