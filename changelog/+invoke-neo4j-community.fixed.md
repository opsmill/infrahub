`uv run invoke demo.start` and the other `invoke` tasks now start Neo4j Community by default, matching the Docker Compose install. To run Neo4j Enterprise with online backup and the Prometheus metrics endpoint, set `NEO4J_DOCKER_IMAGE` to an Enterprise image, for example `neo4j:2026.05.0-enterprise`. `DATABASE_DOCKER_IMAGE` takes precedence over `NEO4J_DOCKER_IMAGE`, so if you set it, set it to the Enterprise image instead. If your local `invoke` database was created with Neo4j Enterprise, keep the database image set to an Enterprise image or delete the database volume, because Neo4j Community could not open a database created by Neo4j Enterprise in our upgrade tests.
