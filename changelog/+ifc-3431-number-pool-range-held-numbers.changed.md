Changing the ranges of a user-created Number Pool is now refused when the change would leave a number the pool tracks outside every range of the pool. This applies to adding, updating or deleting a range, and to updating the pool's `ranges`, `start_range` or `end_range`. The error lists each object holding such a number, the branch holding it, and the value on that branch, for every live branch. A number that is already outside every range is listed too, until a range covering it is added.
