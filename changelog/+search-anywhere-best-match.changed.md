Search anywhere now lists first the node whose display label or name equals the search text, then the nodes whose label starts with it or contains it, then the nodes matched on another attribute. Nodes and groups are ranked in one list, so a search returns at most `limit` results in total instead of up to `limit` nodes plus `limit` groups. Searching while viewing a past date with the time machine now returns the nodes as they were at that date. Search anywhere no longer searches the values of Text area, JSON and List attributes.
