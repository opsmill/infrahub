Fixed the Activities page slowing down as the activity log grows. The account, branch and sub-activity filters now match events by ID, the newest events are read first, and events older than 180 days are returned when the activity log retention is longer than 180 days. Loading more events now continues from the time of the oldest event shown, so events recorded while you scroll are no longer shown twice or skipped. Filtering by the name of a branch that was deleted and then created again now shows only the events of the current branch. An `InfrahubEvent` query without `since` now returns events from the activity log retention before `until`, or from at least 180 days before `until` when `PREFECT_SERVER_SERVICES_DB_VACUUM_ENABLED` does not turn on `events`, instead of from 180 days before today.
