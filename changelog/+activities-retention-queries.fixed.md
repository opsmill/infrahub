Fixed the Activities page slowing down as the activity log grows. The account, branch and sub-activity filters now match events by ID, the newest events are read first, and events older than 180 days are returned when the task manager keeps them longer. Loading more events now continues from the time of the oldest event shown, so events recorded while you scroll are no longer shown twice or skipped. Filtering by the name of a branch that was deleted and then created again now shows only the events of the current branch.
