Fixed deleting a branch-agnostic node, which removes it from every branch at once, while a branch still depends on it. The delete now checks every branch, including the branch where it is requested, and fails when a branch holds a node that has a mandatory relationship to a node deleted on that branch, or a node that a cascading delete from the branch-agnostic node would remove there but does not reach on the branch where the delete is requested. A branch-aware node reached by a cascading delete is still deleted only on the branch where the delete is requested. Each error names the blocking node and every branch where it blocks the delete.
