Fixed deleting a branch-agnostic node, which removes it from every branch at once, while another branch still depends on it. When the nodes to delete include a branch-agnostic node, whether the delete names it or a cascading delete reaches it, the delete now checks every branch and fails when a branch holds a node that has a mandatory relationship to a node deleted on that branch. Each branch is checked against its own schema, so a relationship that is mandatory on one branch only blocks the delete on that branch only. A branch-aware node reached by a cascading delete is deleted only on the branch where the delete is requested, so on every other branch a mandatory relationship from that node to the branch-agnostic node also blocks the delete. Each error names the blocking node and every branch where it blocks the delete. Before any delete, the check now reads only the relationships of the nodes being deleted, instead of every relationship with the same identifier in the database.
