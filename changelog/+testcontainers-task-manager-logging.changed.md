The task manager containers of the `infrahub-testcontainers` stacks, including the separate background services container, now take their log format and level from `INFRAHUB_TESTING_PRODUCTION` and `INFRAHUB_TESTING_LOG_LEVEL`, as the API server and task worker containers already do. With the default `INFRAHUB_TESTING_PRODUCTION=false`, their Infrahub log lines are text with `key=value` fields.
