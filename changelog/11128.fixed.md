Fixed GraphQL queries failing with "At most, one relationship expected" when they requested a relationship that allows a single peer but holds more than one in the database, such as the parent of a hierarchical object with two parents. This stopped the detail page of such an object and the list page of its kind from loading. The query now returns one of the peers, and the breadcrumb on the detail page warns that the object or one of its ancestors has more than one parent and names the other ancestors. Expanding both parents of such an object in the hierarchy tree no longer hides other objects from the tree.
