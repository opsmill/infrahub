Redesigned the IP prefix pool and IP address pool details page on the number pool page's layout. The header reads the pool type, its namespace and its defaults in one line, followed by any attribute or single relationship that a schema extension adds to the pool. The resource prefixes card shows how full the whole pool is, then each resource prefix with its usage on the default branch and on the current branch. When every resource prefix is of a kind that supports an allocation weight, the card shows each weight that is set and lists the heaviest resource prefix first. The prefixes or addresses that the selected resource prefix holds, with their reservation identifier, kind and ID, load in the main table as you scroll, with a Retry button when a page fails to load, and the resource prefix's name above the table opens its IPAM page. The selected resource prefix is part of the page link, and the Actions menu gathers copy, navigation, edit, groups and delete.
