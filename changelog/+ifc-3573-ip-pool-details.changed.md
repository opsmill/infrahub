Redesigned the IP prefix pool and IP address pool details page on the number pool page's layout. The header reads the pool's namespace and defaults in one line. The resource prefixes card shows how full the whole pool is, then each resource prefix with its usage on the default branch and on the current branch. When every resource prefix kind has an allocation weight, the card shows each weight and lists the heaviest resource prefix first. The allocations of the selected resource prefix load in the main table as you scroll, and the resource prefix's name above the table opens its IPAM page. The selected resource prefix is part of the page link, and the Actions menu gathers copy, navigation, edit, groups and delete.
