Added a short-lived per-process cache of the account an API token resolves to and of the permissions loaded for an account on a branch, so a burst of requests from one client no longer repeats the three authentication queries on every request; the window is set by INFRAHUB_SECURITY_AUTH_CACHE_TTL_SECONDS (5 seconds by default, 0 disables), and a revoked token, a deactivated account or a permission change takes effect within it.
