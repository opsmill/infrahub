Added user and global preferences as internal `StandardNode` objects (not schema nodes): `GlobalPreference` holds organisation-wide defaults (`date_format`, `timezone`) as a lazily-created singleton, `UserPreference` stores per-account overrides keyed by `account_id`, and the new `InfrahubEffectivePreferences` GraphQL query returns the merged effective values for the calling user. User preferences are private by construction — there is no generic query and the custom query/mutations only ever touch the caller's own row.
