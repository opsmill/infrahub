Added telemetry to find which component makes an instance slow. When the Python SDK sends the trace context, a background task shares one trace with the API calls and database queries it sends. `INFRAHUB_TRACE_SAMPLE_RATIO` sets the share of recorded traces (default 0.1), and an administrator can raise it for up to 24 hours without a restart through `/api/troubleshooting/trace-sample-ratio`. New metrics show long query and request durations, connection pool usage and task worker queue delays. Traces no longer contain single sign-on secrets and mask personal data, the bundled Grafana dashboards work in any Grafana, and the Compose observability stack turns tracing on. `gunicorn` must start with `--config backend/infrahub/serve/gunicorn_config.py`, as the Compose files and Helm charts do.
