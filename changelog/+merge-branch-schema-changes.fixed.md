Fixed merging a branch, merging its Proposed Change and rebasing a branch being accepted when a node on the default branch, created or changed after the branch was created or last rebased, does not comply with a schema change made on the branch. Infrahub now refuses the operation for an attribute made unique or mandatory, a uniqueness constraint added, a mandatory attribute added without a default value, a mandatory relationship added, the kind of an attribute changed, a regular expression, an enum or a length limit added or changed, and an element of a number pool's allocation scope removed or made optional.
