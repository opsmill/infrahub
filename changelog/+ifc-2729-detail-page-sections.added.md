Added one card per field section on the detail page of an object: each card shows the section description under its title and its own Extra toggle when it holds extra fields, and the card of a section with `collapsible: true`, the default, can be collapsed. The Details, Profile and Template cards cannot be collapsed. A section with a negative order weight is shown above Details, the detail page of a profile shows a Profile card with the profile name and priority first, and the detail page of an object template shows a Template card with the template name first.
