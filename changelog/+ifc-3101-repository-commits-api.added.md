Added the GraphQL API for repository git visibility, ahead of the read path that fills it in. `InfrahubRepositoryCommits` answers for the branch you are viewing with the remote branch or tracked ref it follows and the commit Infrahub has imported, and reports the commit list itself as unavailable until a later release reads it from a worker's copy. `InfrahubRepositoryBranchDrift` and `InfrahubReadOnlyRepositoryCheckRefs` are published alongside it so consumers can build against the full surface: the drift query returns a row for each branch it tracks, carrying the ref and the commit that branch resolves, reporting the comparison against the remote as unavailable for now and reporting a branch with nothing tracked as not tracked; and the refs check accepts a request and returns a task id without yet contacting the remote.
