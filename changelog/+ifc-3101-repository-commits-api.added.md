Added the GraphQL API for repository git visibility, ahead of the read path that fills it in. `InfrahubRepositoryCommits` answers for the branch you are viewing with the remote branch or tracked ref it follows and the commit Infrahub has imported, and reports the commit list itself as unavailable until a later release reads it from a worker's copy. `InfrahubRepositoryBranchDrift` and `InfrahubReadOnlyRepositoryCheckRefs` are published alongside it so consumers can build against the full surface: the drift query returns a row for each branch it compares, carrying the ref and the commit that branch resolves and reporting the comparison against the remote as unavailable for now, with a read-only branch that has imported nothing reported as not tracked and a read-write branch that Git does not synchronise left out of the rows entirely; and the refs check accepts a request and returns a task id without yet contacting the remote.
