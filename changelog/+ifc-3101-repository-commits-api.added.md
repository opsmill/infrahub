Added the GraphQL API for repository git visibility: InfrahubRepositoryCommits returns a paged commit log for a repository on the branch you are viewing, InfrahubRepositoryBranchDrift returns per-branch drift, and InfrahubReadOnlyRepositoryCheckRefs asks Infrahub to check a read-only repository's remote refs now. Both queries answer with the repository, branch, tracked ref and imported commit that Infrahub holds; the values read from a worker's clone report as unavailable until the read path ships in a later release.
