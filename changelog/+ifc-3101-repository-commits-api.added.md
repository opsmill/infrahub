Added the GraphQL API for repository git visibility. `InfrahubRepositoryCommits` answers for the branch you are viewing with the remote branch or tracked ref it follows, the commit Infrahub has imported, and a paged commit log read live from a worker's local copy, each commit labelled as imported, pending, history, unrelated or at the remote head. It reports when the remote history was rewritten, when the imported commit no longer exists in the local copy, and when a read-only repository's tracked branch or tag has been deleted upstream as of the worker's last fetch, in which case it still lists the history Infrahub is running. A worker that has no local copy yet answers that the log is not available and starts a single background clone that reaches every worker; a read-write repository that has imported nothing yet is instead left to its next sync, which creates the copy along with the first import. `InfrahubRepositoryBranchDrift` and `InfrahubReadOnlyRepositoryCheckRefs` are published alongside it so consumers can build against the full surface: the drift query returns a row for each branch it compares, carrying the ref and the commit that branch resolves and reporting the comparison against the remote as unavailable for now, with a read-only branch that has imported nothing reported as not tracked and a read-write branch that Git does not synchronise left out of the rows entirely.
