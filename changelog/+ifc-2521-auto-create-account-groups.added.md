Infrahub can now auto-create `CoreAccountGroup` rows from external identity-provider claims on SSO login. Set `security.auto_create_groups_filter` (env: `INFRAHUB_SECURITY_AUTO_CREATE_GROUPS_FILTER`) to a regex with an optional `(?P<name>...)` named capture to opt in. A per-login cap is configurable via `security.auto_create_groups_max_per_login`. Auto-created groups carry the configured provider name on their read-only `origin` attribute for audit. Three event types — `GroupAutoCreatedEvent`, `GroupAutoCreateRejectedClaimEvent`, `GroupAutoCreateCapBreachEvent` — are emitted on the event bus.
