Changed the Docker Compose file of the observability stack, `docker-compose-observability-standalone.yml`, to turn tracing on for the API server and the task workers, with traces sent to the Tempo service of the stack and a sampling ratio of 0.1 that `INFRAHUB_TRACE_SAMPLE_RATIO` changes; set `INFRAHUB_TRACE_ENABLE=false` to turn it off. A Compose deployment without the observability stack keeps tracing off.
