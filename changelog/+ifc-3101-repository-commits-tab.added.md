The repository page has a new Commits tab. Once Infrahub can read a repository's commit history, the tab lists the commits of the branch you are viewing, newest first, with the short hash, summary, author and date of each one. It marks the commit Infrahub has imported and the current head of the remote, shows how many commits are pending import, and shows a notice when the tracked ref was rewritten so the imported commit is no longer part of its history. On a branch that does not sync with Git and holds a commit of a read-write repository, the tab lists the history of the repository's default branch, says how many commits the branch is behind it or that it is up to date, marks those commits as behind and asks for a rebase to use them; when the branch has diverged from the default branch, for example after a force push, it asks for a rebase instead. A repository added on that branch still reports its commits as pending import until the branch is merged. The tab title shows how many commits are waiting and whether an import or a rebase brings them, and a warning when the history was rewritten, the imported commit is missing from the remote or the tracked ref was deleted. The tab says when the listing was last updated, and each commit has a menu to copy its full hash or, for repositories hosted on GitHub, view the commit on GitHub.

Until Infrahub can read a repository's commit history, the tab says the commit log is not available.
