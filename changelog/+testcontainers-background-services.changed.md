When the `infrahub-testcontainers` stacks run the task manager background services in a container of their own, as they do when `INFRAHUB_TESTING_TASKMGR_SCALEOUT` is set, they now start them with `infrahub tasks background-services` instead of `prefect server services start`, so they need an Infrahub image that has this command. To run an earlier image in this setup, set `INFRAHUB_TESTING_TASKMGR_BACKGROUND_SVC_COMMAND` to `prefect server services start`, which does not apply the `task_manager.retention` settings, or install the `infrahub-testcontainers` version that matches the image.
