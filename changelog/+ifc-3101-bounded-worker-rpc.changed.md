Bounded every message-bus RPC by the new `INFRAHUB_BROKER_RPC_TIMEOUT` setting (30 seconds by default), so a request whose worker never answers now fails with the catalogued `WORKER_TIMEOUT` error naming the operation and how long to wait before retrying, instead of hanging. Adding a repository benefits directly: an unanswered connectivity check now removes the half-created repository, so you can simply add it again.
