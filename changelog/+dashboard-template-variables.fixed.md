Fixed the bundled Grafana dashboards so that their panel queries select job, instance and container values through dashboard variables instead of fixed values. Each variable defaults to the value the panels used before: `job` and `instance` on the Neo4j dashboard, `log_containers` and `log_containers_excluded` on the log panels of the Infrahub dashboard, and `task_manager_job`, `task_manager_service` and `task_worker_service` on the Prefect dashboards.
