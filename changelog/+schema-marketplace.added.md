Added a Schema Marketplace page. Install ready-made schemas from the Infrahub Marketplace either directly into a running instance via the schema-load API, or into a writable Git repository so the YAML stays version-controlled. When no writable Git repository is configured, the page also renders copy-pasteable `infrahubctl marketplace download` + `infrahubctl schema load` commands. Operators can override the Marketplace URL with the `INFRAHUB_MARKETPLACE_URL` environment variable (default `https://marketplace.infrahub.app`) — the same variable is read by `infrahubctl marketplace download`.
