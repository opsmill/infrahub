Added a Schema Marketplace page. Install ready-made schemas from the Infrahub Marketplace into a Git repository (via the UI) or directly into a running instance with `infrahubctl marketplace download` + `infrahubctl schema load` when no writable repository is configured. The home page now shows a Schema Marketplace tile with a Get-started call-to-action on empty instances, replacing the first-run wizard. Operators can override the Marketplace URL with the `INFRAHUB_MARKETPLACE_URL` environment variable (default `https://marketplace.infrahub.app`).
