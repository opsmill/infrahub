A schema load is now refused with HTTP 422 when it frees an attribute name or a kind and gives it to another attribute or kind in the same load: swapped or chained attribute renames, an attribute added or renamed under the name of a renamed or removed attribute, an attribute name freed on a generic and taken on a node that inherits from it (or the other way round), swapped kind names, and a new kind added under the name of a renamed kind. These loads could put attribute values on the wrong attribute, lose values, move objects to the wrong kind or lose the new kind, so load the changes in separate steps instead.
