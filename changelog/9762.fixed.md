Branch-agnostic attributes and relationships on branch-aware objects no longer stay reserved forever after the object is deleted. Previously the value was left in place for every branch, so it still counted towards uniqueness constraints and an allocated resource pool value stayed allocated to an object that no longer existed. The value is now released once no branch can still read the object, and released pool values become allocatable again. Upgrading releases the values earlier versions left behind. See [Deleting a branch-agnostic attribute or relationship](https://docs.infrahub.app/schema/branch-awareness#deleting-a-branch-agnostic-attribute-or-relationship).
