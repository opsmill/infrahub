Fixed GraphQL queries failing with a "Cannot return null for non-nullable field" error when they requested `node_metadata` on a relationship whose peer kind is a generic. An empty cardinality-one relationship, such as the `parent` of a node at the top of a hierarchy, now returns `node` and `node_metadata` as null. The `ancestors` and `descendants` of a hierarchical node now return the `node_metadata` of each node.
