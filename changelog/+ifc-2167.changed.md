The task manager no longer holds one automation for each schema kind and each branch with its own schema to detect changes to display label templates, human-friendly IDs and Jinja2 computed attribute templates that read only their own object. Infrahub now records the display label and human-friendly ID template fingerprints in the database, compares Jinja2 computed attribute templates with the default branch schema, and recomputes the stored values of a kind when its template changes, as before. The upgrade deletes the existing automations and copies the display label and human-friendly ID fingerprints they hold into the database, so the first schema update after the upgrade does not recompute the values of every kind.
