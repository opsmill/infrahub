Fixed GraphQL queries silently returning missing or null values when a selection reached a field through a fragment nested inside an inline fragment, or selected the same field more than once under one response key. Repeated selections now merge instead of one overwriting the other, whether they arrive as repeated fields, sibling fragment spreads, sibling inline fragments, or the same root field selected twice (for example `BuiltinTag { count }` alongside `BuiltinTag { edges { ... } }`). The backend reads the union of everything the query selects at every nesting depth; queries whose dropped field was non-null previously failed outright with a "Cannot return null for non-nullable field" error.
