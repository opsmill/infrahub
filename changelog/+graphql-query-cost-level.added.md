Added the estimated cost of each stored GraphQL query: the new `cost_level` attribute of `CoreGraphQLQuery` is `high` when the worst-case database rows estimated from the GraphQL query cost statistics are above `INFRAHUB_GRAPHQL_COST_HIGH_COST_DATABASE_ROWS` (250,000 by default), `low` otherwise and `unknown` when the query cannot be estimated, and `cost_estimate` holds the figures. Infrahub estimates a stored query when it is created or changed and after each refresh of the statistics.
