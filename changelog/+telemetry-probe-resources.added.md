Added `infrahub telemetry probe-resources`, which reports the CPU and memory allocation the running process sees together with the evidence behind it: the control group it resolved to, the limit files found at each level of that path, and the whole-host figures for comparison. The command reads only local files and needs no database, cache or configuration, so it can explain a deployment whose reported allocation looks wrong even when that deployment is otherwise unhealthy. Nothing is transmitted; output goes to stdout as tables, or as JSON with `--json`.
