Fixed a merge failure (`ResourceNotFoundError: Multiple diffs for branch ... with tracking_id ...`) that occurred when merging a proposed change whose source branch had been rebased. Rebasing a branch left its pre-rebase diff behind under the same tracking id, so the merge task's single-diff lookup found more than one diff. Recalculating a branch's tracked diff now removes any other diff carrying the same tracking id, including one left outside the branch's new time range by a rebase.
