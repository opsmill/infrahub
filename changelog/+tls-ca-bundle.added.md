Added the `INFRAHUB_TLS_CA_BUNDLE` setting, a CA bundle given as a file path or as PEM text and trusted by every component that opens outbound TLS connections, including git repositories and S3 object storage, so Infrahub can run against a private certificate authority without a custom Docker image; git also gained `INFRAHUB_GIT_TLS_CA_FILE` and `INFRAHUB_GIT_TLS_INSECURE`. Every component CA setting now accepts PEM text as well as a path and is validated at startup.
