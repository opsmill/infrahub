When a read-write repository's default branch differs from Infrahub's default branch, a remote branch named like Infrahub's default branch cannot be imported. Infrahub now records that skipped branch as a warning in the repository's Tasks tab, instead of only in the worker's process log. The warning appears when the repository is connected on Infrahub's default branch, and again on a synchronization that imports a branch or sees a new commit on the skipped branch. A repository added on another Infrahub branch imports no other remote branches until that branch is merged, so its first warning comes from such a synchronization after the merge. Successful synchronizations where nothing changed on the remote add no task. With several task workers, a push to the skipped branch is not always reported, and can be reported by more than one worker.
