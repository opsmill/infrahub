Added the `infrahub_db_query_available_after_seconds` Prometheus histogram, recording the server-side time Neo4j takes to make the first record available (`result_available_after`). It is scoped to the permission-check queries the request admission path relies on (`account_global_permissions`, `account_object_permissions`) and labelled by `query`, `type`, and `runtime`, giving a database-health signal isolated from Infrahub-side processing.
