Added a `/api/health` endpoint for load balancer and Kubernetes probe integration. It reports a per-dependency status for the backing services Infrahub relies on — database, message bus, cache, task manager, and the task manager's backing store (`task_manager_db`, checked through the task manager's readiness endpoint) — so a backing-store outage is pinpointed instead of only surfacing as a degraded task manager. Anonymous telemetry now includes a point-in-time snapshot of the same health information, so a degraded deployment can be observed remotely; a failure while gathering health never prevents the rest of the telemetry from being sent.
