Global initialization locks now expire automatically after a configurable time-to-live (20 minutes by default, set via `INFRAHUB_CACHE_INIT_LOCK_TTL_MINS`). Previously, if a worker died while holding the task-manager or registry initialization lock, the lock was never released and Infrahub could not start until the key was manually deleted from Redis. The lock now auto-expires so the platform recovers on its own. This applies to the Redis cache driver.
