Computed attributes, display labels, human-friendly ids and Profile refresh no longer run twice for a change on a branch that carries its own schema or its own repository commit. The default-branch automation excluded the branches with their own automation through a list of negated branch names, but Prefect combines the patterns of one label with OR, so with two or more such branches the filter excluded nothing and every event matched both automations. The exclusion is now one negation per related-resource filter, which Prefect combines with AND.
