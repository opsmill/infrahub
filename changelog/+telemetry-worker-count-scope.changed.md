The telemetry `workers.total` and `workers.active` counts now cover task-worker processes only, matching the task-worker resource figures in the same block. API server processes are counted in the new `server.total` and `server.active` instead, so the previous all-workers figure is `workers.total + server.total`. A snapshot that carries a `server` block uses the new counting, which lets a consumer continue an existing all-workers series across the change.
