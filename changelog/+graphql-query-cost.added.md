Added the cost of each field of a GraphQL query: a request sent to `/graphql` or `/api/query` with the header `X-Infrahub-Query-Cost: details` returns the nodes, resolver calls and database rows of each top-level and relationship field next to an expected and a worst-case estimate, and the new `cost_estimate` field of `InfrahubGraphQLQueryReport`, with its optional `variables` argument, returns the estimate without running the query, using statistics that a daily workflow computes.
