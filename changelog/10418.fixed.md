Loading a schema now fails when an extension targets a kind in a restricted namespace, such as `Core`, `Builtin`, `Profile` or `Template`, in the same way as defining a node in one of those namespaces fails. Before this fix, an extension could add attributes and relationships to built-in kinds such as `BuiltinTag` or `CoreNumberPool`, and could remove existing ones: removing the `password` attribute from `CoreAccount` made login fail. After the upgrade, a schema file or Git repository that extends a built-in kind fails to load until you remove that extension.
