Resource-allocation telemetry now resolves the running process's own control group from `/proc/self/cgroup` and honours limits enforced on any ancestor of it, instead of reading only the apparent control-group root. Deployments without a private cgroup namespace — older container runtimes, an explicit host namespace, or services limited by systemd units — previously reported no CPU assignment and the whole host's memory as the component's capacity, overstating the compute allocated to Infrahub. Environments with a private namespace, the default for current container runtimes, are unaffected.
