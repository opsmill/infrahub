Changing the members or subscribers of an internal GraphQL query group no longer emits an `infrahub.node.updated` event for each of those nodes, nor for the group's stored GraphQL query. Infrahub updates these groups every time a transform or artifact runs its query, and in a large data load these events were about 5% of all events. Webhooks and automations that listen to `infrahub.node.updated` no longer receive them. The group's own events and its `infrahub.group.member_added` and `infrahub.group.member_removed` events are unchanged.
