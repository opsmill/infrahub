Looking up a node by ID now enforces the requested kind. Previously, a query or mutation that resolved a node by ID accepted a node of any kind, so a caller could supply the ID of an unrelated node and, through the follow-up error, read back that node's kind. Such a lookup now returns the same "not found" result whether the ID belongs to a node of another kind or to no node at all, so it can no longer be used to probe the kind of arbitrary nodes.
