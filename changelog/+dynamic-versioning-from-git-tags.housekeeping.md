`infrahub-server` and `infrahub-testcontainers` now derive their version from the `infrahub-v*` git tags at build time (via hatch-vcs) instead of a static `version` field in `pyproject.toml`. Releases no longer require a version-bump PR. Local builds from a fresh clone need the tags fetched (`git fetch --tags`); a checkout with no reachable tag still builds, using a development fallback version.
