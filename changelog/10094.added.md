Export the user-defined schema of a branch with `GET /api/schema/export` or `infrahubctl schema export`, and load the result into another instance without editing it. The default `brief` mode leaves out every value that Infrahub derives again on load, such as labels and order weights; the `full` mode includes them, so loading the export into an instance that already has the schema replaces those values. Each export records the Infrahub version that produced it in a new `infrahub_version` field, which schema loads accept and ignore.
