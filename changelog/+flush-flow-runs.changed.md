Breaking: removed the `--days-to-keep` and `--batch-size` options of `infrahub tasks flush flow-runs`. The command now deletes the finished task runs older than `task_manager.retention.task_history`, with their logs and artifacts, through the task manager, and prints its progress. Its new `--rewrite` option then rewrites each task history and activity log table whose live rows hold less than half of its disk space, to return that space, for example after the upgrade or after lowering a retention. A rewrite needs free disk space for a copy of what the table keeps, and tasks that write to a table wait while it is rewritten. The command prints the tables it rewrote, the ones it left because most of their space is in use, and the ones that stayed locked. The `infrahub-taskmanager flush flow-runs` maintenance tool passes these options too, so use a release of the tool that supports this change, and set the task history retention instead of a number of days.
