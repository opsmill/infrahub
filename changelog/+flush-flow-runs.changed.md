Breaking: removed the `--days-to-keep` and `--batch-size` options of `infrahub tasks flush flow-runs`. The command now deletes the finished task runs older than `task_manager.retention.task_history`, with their logs and artifacts, through the task manager, and prints its progress. Its new `--rewrite` option then rewrites the task history tables to return their disk space, whatever the deletes freed; each table is locked while it is rewritten, so run it in a maintenance window, for example after lowering `task_history`.
