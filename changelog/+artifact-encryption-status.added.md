Added a read-only encryption attribute on artifacts (plaintext, encrypted or unreadable), a check that finds from the stored file's header whether the current key can read it, and indicators on the artifact page: a warning for an artifact stored without encryption while encryption is enabled, a green badge with a lock for an artifact that a check confirmed as encrypted and whose content the server serves (the badge is not shown when the server refuses the content because it failed its integrity check, or when the file is missing), and an error for an encrypted artifact that the current key cannot read.
