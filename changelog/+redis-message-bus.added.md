Added an experimental Redis Streams driver for the message bus (`INFRAHUB_BROKER_DRIVER=redis`), allowing Infrahub to run without RabbitMQ by reusing the Redis instance already required for caching. The driver can connect through `INFRAHUB_BROKER_URL`, which accepts the same `redis://`, `rediss://`, `redis+sentinel://` and `rediss+sentinel://` URLs as `INFRAHUB_CACHE_URL`, so it can reach Redis through Redis Sentinel and follow a failover.
