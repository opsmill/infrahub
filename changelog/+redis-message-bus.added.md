Added an experimental Redis Streams driver for the message bus (`INFRAHUB_BROKER_DRIVER=redis`), allowing Infrahub to run without RabbitMQ by reusing the Redis instance already required for caching. The driver requires Redis 6.2 or later. It can connect through `INFRAHUB_BROKER_URL`, which accepts the same `redis://`, `rediss://`, `redis+sentinel://` and `rediss+sentinel://` URLs as `INFRAHUB_CACHE_URL`, so it can reach Redis through Redis Sentinel and follow a failover. `infrahub events listen` prints the messages of either driver. With tracing enabled, the driver records a producer span for each message it publishes and a consumer span in each process that handles it, with the OpenTelemetry messaging attributes, so the work that a message starts in other processes appears in the trace that published it.
