Added an instance label and an instance color that an administrator sets on the Global preferences page without restarting Infrahub: the label is shown in a badge in the top header and above the logo on the login page and starts the browser tab title, the color is shown as a thin bar at the top of the application pages and the login page and as the color of the browser tab icon, and the `INFRAHUB_INSTANCE_LABEL` and `INFRAHUB_INSTANCE_COLOR` environment variables set deployment defaults that a saved value overrides.
