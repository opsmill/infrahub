Fixed loading a schema file whose attribute, relationship, node or generic IDs come from another Infrahub instance: the load now succeeds, keeps the stored elements and reports each ignored ID as a warning. A load is refused when an ID belongs to another branch, to a deleted element or to a different element, except for an element marked `state: absent` whose ID is in the database but not on this branch: the load skips it and reports a warning. A load is also refused when the same `id` is given to two different elements.
