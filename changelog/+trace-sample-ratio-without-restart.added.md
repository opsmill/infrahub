Added the `/api/troubleshooting/trace-sample-ratio` REST endpoints, documented in the OpenAPI schema. With the `super_admin` permission, `PUT` sets a temporary trace sampling ratio for 1 second to 24 hours on every API server process and task worker without a restart, `DELETE` goes back to the default ratio, and `GET` returns the ratio in force. Each process logs the change when it applies it, and each change is recorded as an `infrahub.trace.sample_ratio_updated` event.
