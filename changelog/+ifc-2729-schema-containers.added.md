Added field sections to the schema: a node or generic can declare a `containers` list, and an attribute or relationship can set `container` to place itself in one of these sections. `details` and names that start with `builtin_` are reserved and cannot be declared. A section has a `collapsible` flag, true by default, and `collapsed: true` requires `collapsible: true`. Generated profiles get a `builtin_profile` section, with order weight -100, that holds `profile_name` and `profile_priority`, and generated object templates get a `builtin_template` section, with order weight -100, that holds `template_name`; neither section can be collapsed. The schema API returns both properties, and marks the sections a node takes from a generic with `inherited: true`. The schema viewer lists the sections of a kind in a Containers tab and shows the section of each attribute and relationship.
