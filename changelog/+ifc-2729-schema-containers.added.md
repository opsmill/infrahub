Added field sections to the schema: a node or generic can declare a `containers` list, and an attribute or relationship can set `container` to place itself in one of these sections. `details` and names that start with `builtin_` are reserved and cannot be declared. Generated profiles get a `builtin_profile` section, with order weight -100, that holds `profile_name` and `profile_priority`. The schema API returns both properties, and marks the sections a node takes from a generic with `inherited: true`.
