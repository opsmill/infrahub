# Resizable Migration to `@infrahub/ui` Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Move the three Resizable wrapper components from `frontend/app/src/shared/components/ui/resizable.tsx` into the shared `@infrahub/ui` package, mirroring the recent ScrollArea migration pattern, and remove `react-resizable-panels` from the app's direct dependencies.

**Architecture:** The component is a thin wrapper around `react-resizable-panels` exporting `ResizablePanelGroup`, `ResizablePanel`, and `ResizableHandle`. The migration creates a new file under `frontend/packages/ui/src/components/resizable/` using the same conventions as `scroll-area` (use `cn` from `tailwind-variants`, no custom prop interfaces because no extra props are added), wires it into the package barrel export, moves the dependency to the package, updates the two callers in the app, and deletes the original file. While migrating, fold in an unstaged style refinement to `ResizableHandle` (drop `relative`, add `rounded-full`, use `bg-cyan-600` for hover/focus).

**Tech Stack:** React 19, TypeScript 5.9, Tailwind CSS 4.2, `tailwind-variants` (`cn` helper), `react-resizable-panels` 4.10, Storybook (`@storybook/react-vite`), Vite 8, pnpm.

**Spec:** `docs/superpowers/specs/2026-04-30-resizable-migration-design.md`

## Task 1: Create the migrated `resizable.tsx` in `@infrahub/ui`

**Files:**

- Create: `frontend/packages/ui/src/components/resizable/resizable.tsx`

- [ ] **Step 1: Create the component file**

Create `frontend/packages/ui/src/components/resizable/resizable.tsx` with this exact content:

```tsx
import * as ResizablePrimitive from "react-resizable-panels";
import { cn } from "tailwind-variants";

export function ResizablePanelGroup({ className, ...props }: ResizablePrimitive.GroupProps) {
  return (
    <ResizablePrimitive.Group
      className={cn("flex h-full w-full aria-[orientation=vertical]:flex-col", className)}
      {...props}
    />
  );
}

export const ResizablePanel = ResizablePrimitive.Panel;

export function ResizableHandle({ className, ...props }: ResizablePrimitive.SeparatorProps) {
  return (
    <ResizablePrimitive.Separator
      className={cn(
        "w-0.5 rounded-full bg-transparent outline-hidden",
        "hover:bg-cyan-600",
        "focus-visible:bg-cyan-600",
        className,
      )}
      {...props}
    />
  );
}
```

Notes on intentional differences from the source:
- `classNames` (app util) → `cn` from `tailwind-variants` (matches `scroll-area.tsx`).
- `ResizableHandle` className: drop `relative`, add `rounded-full`, replace `bg-custom-blue-600` with `bg-cyan-600` (folds in the unstaged working-tree change).
- Trailing comma after `className` argument matches the formatter style used in `scroll-area.tsx`.
