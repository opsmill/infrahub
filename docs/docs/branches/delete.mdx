---
title: Delete a branch
---

After a branch has served its purpose — whether it's been merged, abandoned, or superseded — it can be deleted. All changes are preserved in the commit history of the default branch, so deleting a branch never loses data.

Once deleted, a branch enters a terminal state and can no longer be updated. Creating a Proposed Change against it, rebasing it, and triggering validation on it are all blocked.

## Three ways to delete a branch

Branches can be deleted in three ways:

- **Manually** from the branch detail view, with an option to also delete the corresponding Git branch when one is linked.
- **Automatically after merge** when `delete_branch_after_merge` is enabled in the [configuration](../reference/configuration.mdx). The branch is deleted immediately after a successful merge, whether initiated through a direct branch merge or a Proposed Change.
- **Automatically including the Git branch** when `delete_git_branch_after_merge` is also enabled. Git deletion runs asynchronously and failures are recorded in the repository task log without blocking the Infrahub branch deletion.

## Automatic branch cleanup after merge

Infrahub can automatically delete a branch after it is successfully merged. This keeps your branch list tidy and avoids the operational overhead of manually pruning branches that have already served their purpose.

This behavior is opt-in. Set `delete_branch_after_merge = true` (or `INFRAHUB_DELETE_BRANCH_AFTER_MERGE=true`) to enable it. To also remove the linked Git branch, set `delete_git_branch_after_merge = true` (`INFRAHUB_GIT_DELETE_GIT_BRANCH_AFTER_MERGE=true`) — this has no effect unless Infrahub branch deletion is also enabled.

## What happens after deletion

A deleted branch is in a terminal state:

- Mutations on the branch are blocked
- Proposed Changes cannot be created against it
- Rebasing the branch is no longer possible
- Validation cannot be triggered

The change history that occurred on the branch is preserved in the merged target's commit history (if the branch was merged before deletion). Deleting an unmerged branch discards its accumulated changes — only the data integrated into the target branch is preserved.
