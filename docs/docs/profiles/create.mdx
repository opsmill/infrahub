---
title: Create a Profile
---

Define a reusable set of attribute values for a Profile-enabled node type.

## Prerequisites

- A schema node with `generate_profile: true` (the default for nodes that support Profiles)
- Permission to create objects on the target branch

## Create the Profile

In the GraphQL examples below, replace `<Kind>` with your node kind (e.g. `InfraInterface`), `<profile-name>` with a unique name (3–32 characters), and `<attribute>` / `<value>` with the values you want the Profile to set.

```graphql
mutation {
  Profile<Kind>Create(
    data: {
      profile_name: { value: "<profile-name>" }
      profile_priority: { value: 1000 }
      <attribute>: { value: <value> }
    }
  ) {
    ok
    object { id }
  }
}
```

The `profile_priority` value defaults to `1000`. Lower numbers have higher priority — see [Priority and inheritance](./priority-and-inheritance.mdx).

## Verify

Query the Profile by name to confirm it exists and the values were set:

```graphql
query {
  Profile<Kind>(profile_name__value: "<profile-name>") {
    edges {
      node {
        profile_name { value }
        <attribute> { value }
      }
    }
  }
}
```
