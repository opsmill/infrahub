---
title: Number Pool Attribute Kind
---

The `NumberPool` attribute kind enables the dynamic creation of a `CoreNumberPool` for the specific schema node and attribute.

:::warning Resource pool initial creation

`NumberPool` kind does not create the `CoreNumberPool` resource manager until the first node is created.

:::

## Defining a `NumberPool` attribute {#define-number-pool}

When defining an `NumberPool` attribute, you'll have to define extra `parameters` to define the `start_range` and `end_range` for the `CoreNumberPool` resource manager creation.

```yaml
# vlan.yml
---
version: "1.0"
nodes:
  - name: VLAN
    namespace: Infra
    attributes:
      - name: vlan_id
        kind: NumberPool
        unique: true # Makes the attribute unique and will be assigned from the pool
        read_only: true # Required
        parameters:
          start_range: 1000
          end_range: 10000
      - name: name
        kind: Text
        unique: true
        optional: false
        read_only: true
        computed_attribute:
          kind: Jinja2
          jinja2_template: "Vlan {{ vlan_id__value }}"
      - name: description
        kind: Text
        optional: true
```

## Updating Start/End Ranges

There are two options to update the start/end range of the associated `CoreNumberPool` resource manager.

- Update schema and load in the new schema
- Update the start/end range on the specific resource manager
