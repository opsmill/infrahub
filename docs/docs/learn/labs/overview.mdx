# Labs

A lab is a hands-on Instruqt track: a hosted sandbox environment with Infrahub already running. There's no local setup — click through the exercises directly in your browser, on infrastructure OpsMill provisions for the session.

:::info Hands-on Learning
Instruqt is an online lab platform providing a pre-configured environment so you can focus on learning with hands-on experience.
:::

## [Infrahub: fundamentals to expert](./fundamentals-to-expert)

A 5-track sequence that takes you from a fresh Infrahub instance to a fully automated site deployment, all on one shared demo dataset. Do the tracks in order — each one builds on data created in the last.

## Standalone labs

Prefer a single topic instead of the full sequence? These three labs each stand on their own:

- **[First Tour of Infrahub](./infrahub-introduction)** — a 30-minute overview of Infrahub's core concepts.
- **[Schema Deep Dive](./schema-deep-dive)** — learn how to shape and extend Infrahub's flexible schema.
- **[Deploy Your First Configuration](./deploy-first-configuration)** — generate and deploy a network configuration using Infrahub's artifact feature.
