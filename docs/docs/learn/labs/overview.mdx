# Labs

A lab is a hands-on guided walkthrough hosted on Instruqt, an online lab platform:

- **No setup** — a sandbox environment with Infrahub already running, provisioned by OpsMill for the session. Click through the exercises directly in your browser.
- **Designed for learning** — each lab is scoped and paced so you can focus on the concepts, not on wrangling infrastructure.

## Infrahub: fundamentals to expert

A [5-lab sequence](./fundamentals-to-expert) that puts you on the network automation team of a fictional operator, OtterNet, and gives you a 360° tour of Infrahub's features — schema modeling, enforcement and validation, design-driven Generators, and Transforms — all on one shared demo dataset.

## Standalone labs

Prefer a single topic instead of the full sequence? These three labs each stand on their own:

- **[First Tour of Infrahub](./infrahub-introduction)** — a 30-minute overview of Infrahub's core concepts.
- **[Schema Deep Dive](./schema-deep-dive)** — learn how to shape and extend Infrahub's flexible schema.
- **[Deploy Your First Configuration](./deploy-first-configuration)** — generate and deploy a network configuration using Infrahub's artifact feature.
