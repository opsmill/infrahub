# Integrations

OpsMill maintains three integrations that let other tools consume Infrahub data: Ansible, Nornir, and Infrahub Sync.

## Ansible integration

The Infrahub Ansible Collection adds Infrahub-aware modules, an inventory plugin, and a lookup plugin to your Ansible workflows. The modules manage Infrahub nodes (create, update, delete), branches, and artifacts. The inventory plugin sources playbook hosts from Infrahub instead of static files. The lookup plugin retrieves structured GraphQL data inside playbooks. Use it to drive existing Ansible automation from Infrahub data without maintaining a separate inventory or query layer.

[Ansible Integration documentation ↗](https://docs.infrahub.app/ansible)

## Nornir integration

The Infrahub Nornir plugin makes Infrahub a dynamic inventory source for Nornir via the `InfrahubInventory` plugin. It also ships task functions for working with artifacts: regenerate artifacts for a single host, generate them in batch, or fetch existing ones. Use it to combine the Infrahub data model with the Nornir task framework and Jinja2 templating without managing inventory separately.

[Nornir Integration documentation ↗](https://docs.infrahub.app/nornir)

## Infrahub Sync

Infrahub Sync moves data between Infrahub and other source-of-truth systems — Nautobot, NetBox, and others. Use it to migrate to Infrahub from an existing SoT, or to keep Infrahub in sync with another system during a transition period.

[Infrahub Sync documentation ↗](https://docs.infrahub.app/sync)
