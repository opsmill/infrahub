On an existing instance that holds a lot of task history, run the cleanup step once the instance runs again. It deletes the old task runs quickly and gets their disk space back, and you do not need to stop anything. New and small instances do not need it. See [Clean up old task history after the upgrade](../deploy-manage/maintain-upgrade/upgrade/overview.mdx#clean-up-old-task-history-after-the-upgrade).
