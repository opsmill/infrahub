When the task manager reports at least 100,000 finished task runs older than the task history retention, the last step of the upgrade, `Step 7/7: Task history cleanup`, deletes them and gets their disk space back. On an existing instance that holds a lot of task history, run the cleanup command below once the instance runs again when that step skipped the cleanup and printed the command, or printed `The upgrade goes on without the cleanup`. You do not need to stop anything. New and small instances do not need it. See [Clean up old task history during and after the upgrade](../deploy-manage/maintain-upgrade/upgrade/overview.mdx#clean-up-old-task-history-after-the-upgrade).
