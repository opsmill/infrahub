:::warning Task history older than the retention is deleted

After the upgrade, the task manager deletes finished task runs older than the task history retention, 30 days by default, together with their logs and artifacts, every hour, and this cannot be undone. If you need older runs, set a longer retention on the task manager before you upgrade, for example `INFRAHUB_TASK_MANAGER_RETENTION_TASK_HISTORY=90d` in the `.env` file of a Docker Compose deployment or in the environment of the task manager on Helm. The task manager deletes according to the retention set on the task manager, not on the container that runs `infrahub upgrade`. See [Task history retention](../deploy-manage/run-observe/tasks.mdx#task-history-retention) for the ways to set it.

:::
