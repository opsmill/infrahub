:::warning Task history older than the retention is deleted

After the upgrade, the task manager deletes the finished task runs older than the task history retention, 30 days by default, with their logs and artifacts, every hour. The deletion cannot be undone. If you need older task runs, set a longer task history retention before you upgrade, for example `INFRAHUB_TASK_MANAGER_RETENTION_TASK_HISTORY=90d`:

- With Docker Compose, in the `.env` file.
- With Helm, in the `env` list under `prefect-server.global.prefect` in your values file, or under `infrahub.prefect-server.global.prefect` with the Infrahub Enterprise chart. This list reaches the task manager and, when the background services of the task manager run in a pod of their own, as with the sizing presets of the Infrahub Enterprise chart, that pod too. The hourly deletion then runs in that pod, with the values of that pod. The `env` list under `prefect-server.server` reaches only the task manager.

The retention set on the container that runs `infrahub upgrade` has no effect on the deletion. See [Set the retention](../deploy-manage/run-observe/tasks.mdx#set-the-retention).

:::
