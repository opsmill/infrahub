# Installation

Infrahub Community and Enterprise are deployed as container-based architectures. Install them with Docker Compose on a single host, or with Helm on a Kubernetes cluster. Both methods support either edition: you choose the edition through the compose file URL or the Helm chart.

The installation methods in this section are for non-resilient deployments suitable for development, testing, and single-node production environments. For high-availability production deployments, see [High availability deployment examples](../production-deployment/high-availability.mdx).

## Prerequisites

- Verify your system meets the [hardware requirements](../hardware-requirements.mdx) before installing Infrahub.
- Each installation method has additional prerequisites listed on its own page.

:::info

Allocating more CPU cores to the Neo4j database only improves performance on Infrahub Enterprise, which uses parallel query execution.

:::

## Choose an installation method

| Method                                                              | Editions              | Where it runs                                                          |
|---------------------------------------------------------------------|-----------------------|------------------------------------------------------------------------|
| [Docker Compose](./docker-compose.mdx)                              | Community, Enterprise | A single host with Docker                                              |
| [Helm](./helm.mdx)                                                  | Community, Enterprise | A Kubernetes cluster                                                   |
| [Bare metal](#bare-metal)                                           | Enterprise            | Hosts without containers                                               |
| [Local demo environment](../../../development-resources/local-demo-environment.mdx) | Community             | A clone of the Infrahub repository, for development and demos          |

## Bare metal <EnterpriseBadge /> {#bare-metal}

Infrahub Enterprise supports bare metal installations for customers who require direct hardware deployment without containerization.
