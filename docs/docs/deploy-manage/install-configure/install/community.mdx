# Install Infrahub Community

Infrahub Community and Infrahub Enterprise share one installation guide per method. Choose how you want to run Infrahub Community:

- [Install with Docker Compose](./docker-compose?edition=community) — Run Infrahub on a single host from the compose file published for each release
- [Install with Helm](./helm?edition=community) — Deploy Infrahub on a Kubernetes cluster with the `infrahub` chart
- [Local demo environment](../../../development-resources/local-demo-environment.mdx) — Run Infrahub from a clone of the repository, for development and demos
