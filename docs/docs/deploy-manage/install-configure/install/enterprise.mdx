# Install Infrahub Enterprise <EnterpriseBadge />

Infrahub Community and Infrahub Enterprise share one installation guide per method. Choose how you want to run Infrahub Enterprise:

- [Install with Docker Compose](./docker-compose?edition=enterprise) — Run Infrahub on a single host, with optional sizing presets
- [Install with Helm](./helm?edition=enterprise) — Deploy Infrahub on a Kubernetes cluster with the `infrahub-enterprise` chart and its sizing presets
- [Bare metal](./overview.mdx#bare-metal) — Install Infrahub Enterprise on hosts without containers, with support from OpsMill
