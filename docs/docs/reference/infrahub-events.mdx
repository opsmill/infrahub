# Infrahub events

This document provides detailed documentation for all events used in the Infrahub event system.

:::info
For more detailed explanations on how to use these events within Infrahub, see the [activity](../topics/activity-log) topic.
:::

## Node events

<!-- vale off -->
### Event `NodeMutatedEvent`
<!-- vale on -->
**Description**: Event generated when a node has been mutated
<!-- vale off -->
| Key | Description |  Default Value |
|-----|-------------|---------------|
| **meta.branch** | The branch on which originate this event | None |
| **meta.request_id** | N/A | None |
| **meta.account_id** | The ID of the account triggering this event | None |
| **meta.initiator_id** | The worker identity of the initial sender of this message | 9e141ae6-0846-4d40-82cb-cfcf44ce9e35 |
| **meta.context** | The context used when originating this event | None |
| **meta.level** | N/A | None |
| **meta.has_children** | Indicates if this event might potentially have child events under it. | None |
| **meta.id** | UUID of the event | None |
| **meta.parent** | The UUID of the parent event if applicable | None |
| **meta.ancestors** | Any event used to trigger this event | None |
| **kind** | The type of object modified | None |
| **node_id** | The ID of the mutated node | None |
| **action** | The action taken on the node | None |
| **data** | Data on modified object | None |
| **fields** | Fields provided in the mutation | None |
