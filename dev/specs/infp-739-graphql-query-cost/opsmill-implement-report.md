### Chunk 3: Phase 3, actual counts (T007 to T015)

- Tasks: 9. Done 9, partly done 0, blocked 0.
- Commits: `5a1989ce3b`, `dd89d8bff2`.
- Decisions flagged:
  - Counting starts after the analyzer is built. Reads before that point are not reported: the API key check, the account load, the permission load and, on `/api/query`, the stored-query read. The contracts and `data-model.md` state this limit.
  - The row-sum test measures the reads before counting with a `{ __typename }` request, because those reads use the same query names as reads inside the counted window.
  - Existing behavior found: with `count` selected on a many-cardinality field, the same request without the header ran 21 or 28 queries over 120 runs; without `count` it always ran 16. The query-count test leaves `count` out, and `research.md` D12 records this.
  - Hierarchy fields (`ancestors`, `descendants`) are recorded with the hierarchy kind, the identifier `parent__child` and cardinality `many`.

### Chunk 4: Phase 4, statistics refresh and store (T016 to T024)

- Tasks: 9. Done 9, partly done 0, blocked 0.
- Commit: `9e47331e4e`.
- Decisions flagged:
  - The collector and `publish` take the branch explicitly, so the default branch name is not written as "main" in the code.

### Chunk 5a: Phase 5, estimation tree and estimator (T025, T026, T028, T029, T032)

- Tasks: 5. Done 5, partly done 0, blocked 0.
- Commit: `a8016ef8c9`.
- Decisions flagged:
  - `CostTreeField` gained `parent_kinds`, `selects_nodes` and `max_matching_nodes`. Inline fragments narrow `parent_kinds`, not `concrete_kinds`.
  - The analyzer now keeps the syntax node of each field. Copies of a named fragment share those nodes, so the copy cost stays the same.
  - The worst-case bound equals the brute-force maximum in most tested shapes. It is strictly above it in one shape: persons owning 3, 2 and 1 cars, bound 15, real maximum 14. `tasks.md` T025 and `research.md` D10 state this.
  - The first-step count types live in `models.py`, so the estimator does not import the database layer.

- Commit: `aa051c4406`.
- Decisions flagged:
  - A request with the header always returns the same `data` and `errors` as without it:
    - Variables of the wrong type give cost details with no estimate, without a log entry, because execution already returns that error.

- Commits: `282fefc331` (first-step fixes), `1208e51aa6` (tests for three coverage gaps), `1f9b5320ef` (documentation and schema description).
- Decisions flagged:
  - The first-step peer count now applies the field's `offset` and `limit` to each parent node's peers, all peer kinds together.
