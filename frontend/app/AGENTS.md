## Overview

React TypeScript frontend built with Vite, using Tailwind CSS for styling.

## File Naming

- Components: `kebab-case.tsx`
- Atoms: `kebab-case.atom.ts`
- Tests: `*.test.ts` or `*.test.tsx` (colocated)
- Types: `types.ts` or inline
